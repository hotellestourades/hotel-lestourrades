# 🏨 Hôtel Les Tourrades - Site Vitrine

Site web moderne et responsive pour l'Hôtel Les Tourrades à Cannes La Bocca.

## 📋 Caractéristiques

- ✅ Design moderne et élégant
- ✅ 4 types de chambres (Double, Single, Twin, Triple)
- ✅ Formulaire de réservation par email
- ✅ Galerie photo
- ✅ Section localisation avec loisirs à proximité
- ✅ Responsive (mobile, tablette, desktop)
- ✅ SEO optimisé
- ✅ HTTPS automatique sur Vercel

## 🚀 Déploiement sur Vercel

Voir le fichier `DEPLOIEMENT-VERCEL.md` pour les instructions complètes.
